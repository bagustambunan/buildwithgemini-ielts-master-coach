# My agent: IELTS Master Coach - 4-Skills Preparation & Speaking Simulator
One-liner: A conversational agent that helps IELTS test-takers master all 4 skills (with flagship focus on Speaking and Writing) with a catalog of authentic exam prompts, real-time examiner simulations, and diagnostic band-descriptor rubrics.

Tool coverage:
- Memory: Target band score (e.g. Band 7.5), student persistent error log (speaking filler words/hesitations, recurrent grammar slips, weak essay structures), and topic mastery history across sessions.
- Tools: Fetch authentic IELTS practice prompts (Speaking Part 1/2/3 cue cards, Writing Task 1/2, Reading/Listening exercises), evaluate responses against official Cambridge Band Descriptors (FC, LR, GRA, PR for Speaking; TR, CC, LR, GRA for Writing), and retrieve Band 8/9 model answers and natural collocations.
- Catalog/UI: Speaking Part 2 Cue Cards with 1-min preparation countdowns, diagnostic scorecards (sub-score breakdown with criteria checklists), interactive reading drill cards, and line-by-line error log tables.
- Image gen: Simulated Academic Task 1 visual charts/graphs (line graphs, bar charts, process diagrams) for data description practice, and visual thematic vocabulary mind maps.
- Sandbox: Official IELTS overall band rounding arithmetic (0.25 -> 0.5, 0.75 -> 1.0), speaking pace analytics (Words Per Minute / WPM calculation), and writing text metrics (word count penalty check and lexical diversity score).

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for WPM and official band rounding calculations, speech-to-text / audio integration for real-time Speaking examination.
